Scenario
This program simulates a simple student café purchase. It calculates the total cost based on the quantity of items ordered and the price per item. It also uses comparison operators to check the order information.

Data Types Used
The program uses the four required Dart data types:

int – stores the quantity of items.
double – stores the price and total amount.
String – stores the student's name.
bool – stores whether the student is a member.

Operators Used
The program uses arithmetic and comparison operators.

Arithmetic Operators
* – calculates the total price.

+ – adds values.

~/ – performs integer division.

% – finds the remainder.

Comparison Operators
== – checks if two values are equal.

> – checks if the total is greater than 100.
